## 提交前硬检查

- [ ] 官方规则为当届版本，链接可访问。
- [ ] 题号、队号、文件名和匿名信息正确。
- [ ] 页数、目录、摘要、参考文献和附录符合规则。
- [ ] AI 使用声明、代码/数据附件和引用符合规则。
- [ ] PDF 字体、公式、图表、链接和分页已人工检查。
