# 已废弃的旧质量门（仅供迁移）

> 不再作为验收依据。正式流程请读取 `workflow-gates-v2.md`；其中 G5 为论文写作交接，打包已移至 G6。

## G0 题目与数据盘点

通过条件：

- 题目原文、子问题、硬约束和交付要求已记录。
- 数据文件、字段、单位、范围、缺失和来源已盘点。
- 已区分题目给定假设和团队新增假设。
- 关键歧义已列入待确认项。

## G1 文献证据

通过条件：

- 检索式包含中英文关键词、同义词、机制词和方法词。
- 关键来源具有可验证链接或DOI。
- 证据矩阵覆盖基线、候选方法、限制和检验方法。
- 已区分原文事实、Agent归纳和迁移判断。
- 对矛盾证据和无法访问的来源有明确标记。

## G2 方案冻结

通过条件：

- 已给出变量、参数、单位、假设、目标、约束和算法。
- 至少有一个简单基线，并解释为何选择最终模型。
- 已预注册灵敏度、稳健性、误差和消融检验。
- 已定义失败判据和备用路线。
- 建模手已明确批准当前版本。

只有最后一项满足后，才能把 `PLAN_STATUS.txt` 改为 `FROZEN`。

## G3 实现与运行

通过条件：

- 实现与冻结方案一致。
- 基线和最终模型均可运行。
- 原始数据未被修改。
- 随机种子、依赖、参数、命令和运行日志可追溯。
- 正式结果可由脚本重建，图表可追溯到数据。

## G4 独立检验

通过条件：

- 检验者从文档命令独立复现主要结果。
- 已检查实现与数学方案的一致性。
- 所有关键检验均有状态和证据。
- 严重失败已修复并重新验证，或明确保留为未解决风险。
- 检验不是仅复述实现者的结论。

## G5 手动交接

通过条件：

- 用户已明确下令打包。
- `PROJECT_STATUS.md` 与 `HANDOFF.md` 已更新。
- 包内包含技能、Agent配置、方案、代码、检验报告和复现说明。
- 压缩包没有已知秘密文件。
- 已生成清单和 SHA-256 校验值。
- 未经授权的论文和教材全文未被默认打包。
