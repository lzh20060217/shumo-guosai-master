# 独立检验标准

检验者必须从冻结方案和文档命令独立工作。每项记录 verification_id、task_id、状态、命令与输入、预注册阈值、实际结果、证据路径、偏离、风险和动作。状态为 `PASS / CONDITIONAL / FAIL / NOT_TESTED / NOT_APPLICABLE`；不适用必须解释。

G2-B 的冻结前合成挑战不是 G4 证据。正式 G4 必须使用新的 review/run ID、独立输出目录并从文档命令重新复现；不得把 `model/readiness/verifier-review.md` 的签收计为任何结果检验 `PASS`。

## 一致性与数据

- 逐行核对 `problem/task-requirements.csv`、冻结公式/算法、预处理、代码入口、结果和论文产物。
- 重算原始文件哈希；检查字段、类型、单位、主键、去重、缺失、异常、时间/空间对齐和输出模式。
- 检查插补、编码、标准化、特征选择和调参只在允许的数据范围拟合；排查标签、未来、同实体跨集合泄漏。
- 用小型人工样例验证预处理和关键公式，并检查边界、退化情形、量纲、约束残差和数值稳定性。

## 基线与性能

- 基线和最终模型必须用同一数据、划分、预测时点和指标。
- 检查 Tier 0/1/2 是否遵守冻结的选择函数：预测任务使用同一外层划分、评价单位和主指标；非预测任务使用同一场景集、约束口径和评价设计。不得删除 Tier 2 失败、无增益或超预算记录。
- Tier 2 只有同时通过预注册的增益、区间、稳定性、适用时校准和成本门，才能成为论文主模型；否则验证其按冻结路线退到 Tier 1。Tier 1 失败时核验 Tier 0 是否仍能完整回答并相应限制声明，所有冻结 Tier 失败才支持重开 G2。
- 报告绝对表现、相对增益、运行成本和不确定性；复杂模型无实质增益时不能宣称更优。
- 预测/拟合按题型检查残差、异方差、自相关、交叉验证、滚动回测、校准和分布漂移。
- 排序/评价检查指标方向、权重来源、共线性、重复计量、替代方法和秩相关/Top-k 稳定性。
- 优化检查可行性、约束残差、上下界、不同初值/求解器、最优性间隙和规模扩展。
- 仿真检查收敛、置信区间、暖机期、步长、边界效应和蒙特卡洛误差。

## 灵敏度分析

灵敏度回答“参数或关键输入改变时结论如何改变”，不等于稳健性。必须：

1. 选择会影响论文结论的关键参数、权重、阈值、初值、时间步长或预处理选择，并说明筛选理由。
2. 从预注册表读取基准、物理/统计可行范围、网格或采样分布、重复次数和种子；不得看完结果再缩窄范围。
3. 局部单因素只适用于近似独立、局部线性的说明；存在非线性或交互时使用二维响应面、拉丁超立方、Sobol/Morris 或适合该模型的全局方法。
4. 同时报告输出弹性/变化率、性能变化、排序/决策翻转、阈值跨越、不可行比例和失效区间，并保留完整原始表。
5. 随机模型在每个设置重复运行并给出区间；将参数敏感性与蒙特卡洛噪声分开。
6. 用预注册阈值判定 `PASS/CONDITIONAL/FAIL`。若“无参数”，仍检查关键输入、权重、边界假设或预处理阈值；完全不适用须书面论证。

## 稳健性、压力测试与消融

- 稳健性回答“数据或环境受扰动时结论是否保持”：分别注入缺失、噪声、异常、抽样变化、时段变化、分布漂移或极端场景，扰动强度要有现实依据。
- 压力测试覆盖边界和极端但可能发生的场景，记录何处约束失效或决策反转。
- 消融逐个移除特征、模块、约束或机制；替代模型比较结构选择。报告效果、稳定性和成本，而不只报告最优指标。
- 对输入误差、参数估计误差、模型结构误差和随机误差分别说明；适用时给置信区间、bootstrap、情景区间或概率结果。

## 图表、表格与声明审计

- 从登记的生成脚本重建每个正式 artifact；核对值、排序、单位、小数位、样本范围、图例、误差条和图注。
- artifact 只有在数据、脚本和结论均通过后才可从 `PENDING` 改为 `VERIFIED`。
- `reports/claim-audit.csv` 的每个论文声明必须链接文献 evidence_id、artifact_id 和 verification_id；相关不能写成因果，样本内不能写成普适，条件通过必须保留条件。
- 关键 `FAIL` 或 `NOT_TESTED` 阻塞 G4；`CONDITIONAL` 必须写明允许和禁止的论文措辞。
