# 建模方法选择图谱

先从问题结构和数据条件出发，再选择模型。不要因为资料库中有某种算法就强行套用。

| 问题结构 | 常见基线 | 候选方法 | 首要检验 |
|---|---|---|---|
| 连续量预测 | 均值、线性回归、朴素时间序列 | 回归、ARIMA、状态空间、树模型、神经网络 | 回测、残差、漂移、基线差值 |
| 分类识别 | 多数类、逻辑回归 | 树模型、SVM、集成学习、深度模型 | 分层验证、校准、混淆矩阵、泄漏 |
| 综合评价与排序 | 等权加总 | AHP、熵权、TOPSIS、PCA、模糊评价 | 权重敏感性、排名稳定性、共线性 |
| 资源配置 | 贪心或均分 | 线性、整数、非线性、动态、鲁棒优化 | 可行性、上下界、求解稳定性 |
| 路径与网络 | 最短路、简单中心性 | 网络流、车辆路径、复杂网络、图优化 | 规模扩展、约束残差、扰动场景 |
| 动态演化 | 静态或线性趋势 | 微分方程、差分方程、系统动力学 | 参数识别、稳定性、边界和极限 |
| 随机过程与排队 | 期望值近似 | 马尔可夫链、排队论、蒙特卡洛、离散事件仿真 | 收敛、置信区间、解析或枚举对照 |
| 空间关系 | 全局均值 | 空间回归、插值、聚类、GIS网络 | 空间自相关、尺度效应、外推风险 |
| 多主体行为 | 平均场或规则基线 | Agent仿真、博弈论、演化模型 | 规则敏感性、涌现稳定性、情景分析 |
| 因果或政策 | 相关回归 | 匹配、双重差分、工具变量、因果图 | 识别假设、安慰剂、平行趋势、稳健性 |

## 选择步骤

1. 明确输出是预测、解释、评价、决策还是机制模拟。
2. 明确数据是横截面、时间、空间、网络、实验还是仿真数据。
3. 检查样本量、变量数量、缺失、噪声、标签和可获得的外部信息。
4. 建立最简单可运行基线。
5. 选择复杂模型，并说明它相对基线解决了什么具体缺陷。
6. 在实现前确定比较指标、失败判据和计算预算。

## Tier 0/1/2 与效果保护

每个正式子问题按以下层级组织，而不是按“越复杂越好”排序：

| 层级 | 角色 | 进入条件 | 退出或降级条件 |
|---|---|---|---|
| Tier 0 | 简单、可解释、可重复的最低交付基线 | 标准方法；与其他层同外层划分、评价单位和主要指标 | 仅用于基线或 Tier 1 失败时的最低回答 |
| Tier 1 | 默认竞赛主力模型 | 明确解决 Tier 0 缺陷；理论与应用证据充分；预算内可实现和完整检验 | 失败时先退 Tier 0；所有冻结 Tier 均不能回答题目才重开 G2 |
| Tier 2 | 可选高级候选 | 有潜在额外效果或方法亮点；完成 Tier 0/1 后仍有至少 30% 安全余量 | 无预注册增益、区间不支持、稳定性/校准恶化、超预算或同因失败两次时退 Tier 1 |

Tier 2 升级为论文主模型必须同时通过：主要指标相对 Tier 1 的预注册增益门、区间支持、稳定性门、适用时的校准门和成本门。训练拟合改善不能替代外层效果；不得改变测试集、删除困难样本或更换指标。预测任务保持同一外层划分；非预测任务保持同一场景集、约束口径和评价设计。选择 Tier 1 时只能表述为“当前证据下综合泛化、稳定性、解释性和成本更优”，不能宣称其必然更准确。

## 计算预算

- 在 `model/complexity-budget.csv` 登记单次拟合、外层/内层拟合数、bootstrap/模拟次数、内存、磁盘、最坏总耗时和超预算动作。
- Tier 0 必须能短时间重复；具体时间由当前设备和比赛窗口填写。
- Tier 1 预计全量运行默认不超过可用比赛计算窗口的 40%。
- Tier 2 只有在 Tier 0/1 完成后仍预留至少 30% 给 G4、制图、论文和故障修复时运行。
- 模型复杂度本身既不是创新性证据，也不是效果优越性证据；所有合规候选的成功、失败和无增益结果都要保留。
