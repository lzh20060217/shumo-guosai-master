# 建模与编程手册

## 1. 先判断问题结构

- 连续预测：朴素/线性基线；回归、时间序列、状态空间、树模型等主力；检查外推、回测、残差和漂移。
- 分类识别：多数类/逻辑回归基线；树模型、SVM、集成学习等主力；检查分层划分、混淆矩阵、校准和泄漏。
- 综合评价：等权基线；AHP、熵权、CRITIC、TOPSIS、PCA、模糊评价等候选；检查指标方向、共线性、权重与排名稳定性。
- 优化决策：贪心/均分基线；线性、整数、非线性、动态或鲁棒优化；检查可行性、约束残差、上下界和求解稳定性。
- 动态机理：静态趋势基线；微分/差分方程、系统动力学、状态空间；检查参数识别、稳定性和边界。
- 网络路径：最短路/简单中心性基线；网络流、路径规划、复杂网络；检查规模扩展和扰动场景。
- 随机仿真：期望值或小规模枚举基线；马尔可夫、排队、蒙特卡洛、离散事件仿真；检查收敛和置信区间。
- 因果政策：相关回归只能作基线；因果结论需匹配、DID、IV、因果图等识别设计及其假设检验。

模型名称不是选择理由。必须回答：它利用了什么结构、修复了基线什么缺陷、需要什么假设、如何失败、用什么指标比较。

## 2. 每问模型预算

默认一条主线：一个简单基线 + 一个主力模型。只有两套模型回答不同科学问题或构成必要对照时才并列保留。预处理、特征工程、优化求解器、灵敏度和稳健性通常不算新的模型族。

深度学习的进入条件：样本规模和标签质量足够、结构确实适合、与 Tier 1 同口径比较、外层效果有实质提升、稳定性和时间成本过门。否则不用。

## 3. 跨题链

建立 `problem/task-requirements.csv` 或等价表格，至少记录：task_id、输入数据版本、输出、上游依赖、模型、主要指标、代码入口、结果路径、验证 ID、论文位置。

常见链条：

1. Q1 输出可靠数据、异常标签、质量权重或关键特征；
2. Q2 使用 Q1 产物识别事件、估计状态或建立局部模型；
3. Q3 汇总规律、机制或时空变化；
4. Q4 形成预测、评价或风险分级；
5. Q5 在前述结果上做决策、推广或管理建议。

如果后问没有使用前问产物，必须说明它为何独立，而不是默认重新读取原始脏数据。

## 4. 单一事实源

维护机器可读的结果总表，例如 `outputs/result-summary.json`，以及 `outputs/artifact-manifest.csv`。论文中的每个关键数字至少登记：task_id、含义、数值、单位、数据版本、模型版本、运行 ID、源表、生成脚本、验证状态。

论文初稿与单题报告发生冲突时，以题目原文、冻结方案、运行底表和验证报告为准；不得投票选择“看起来合理”的数字。

## 5. 代码目录与运行记录

推荐：

```text
data/raw/                 原始只读数据
data/processed/           版本化清洗数据
src/                      可复用实现
experiments/              正式运行入口
tests/                    单元、契约和验证测试
outputs/tables/raw/       逐样本/逐场景底表
outputs/tables/final/     论文汇总表
outputs/figures/drafts/   候选图
outputs/figures/final/    论文终图
outputs/logs/             参数、环境、命令和运行日志
reports/                  验证与问题记录
paper/                    Word/LaTeX/PDF
deliverables/             最终交付包
```

固定随机种子；集中管理参数；记录软件版本、输入哈希、完整命令、退出码和耗时。正式结果必须能从命令行脚本重新生成。

## 6. 数据图

- 用代码绘制，默认300 DPI PNG；需要编辑时额外输出 SVG/PDF。
- 图内不放标题，标题由论文图注承担；单位、图例和坐标必须完整。
- 字号按最终插入论文后的尺寸检查，最小一般不低于7.5 pt。
- 不用单一折线图或柱状图重复铺满全文；按证据目的选择分布、关系、误差、敏感性、结构和决策图。
- 图后数据必须可追溯；禁止用图像生成模型制造数据趋势。

## 7. 验证的区别

- 灵敏度：参数或关键输入改变，答案如何改变。
- 稳健性：噪声、缺失、异常、抽样、窗口或环境变化时结论是否保持。
- 消融：移除特征、模块、约束或机制后贡献是否消失。
- 不确定性：输入、参数、结构和随机误差分别有多大。
- 外推检验：超出样本时间、空间或工况后是否仍有依据。

每项在看结果前尽量确定范围、重复次数、指标和失败判据，避免事后挑选漂亮区间。
